# Painel

| Script | Descrição |
|---|---|
| `painel.sh` | Menu interativo central que dá acesso a todos os outros scripts instalados em `~/scripts`. |

## Uso

Depois de rodar o `install.sh` na raiz do repositório:

```bash
painel          # se o atalho global foi criado
# ou
bash ~/scripts/painel.sh
```
